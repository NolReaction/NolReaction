# Сломов Дмитрий

Я Android-разработчик, пишу на Kotlin. Создаю собственные приложения и игры, работаю с Kotlin Multiplatform. В своих проектах занимаюсь интерфейсом, архитектурой, серверной частью и развёртыванием.

В 2026 году окончил бакалавриат РТУ МИРЭА по направлению «Программная инженерия». Сейчас учусь в магистратуре ИТМО на программе «Мобильные и облачные технологии».

## Мои проекты

**[В такт](https://github.com/NolReaction/pinch-music)**  
Разрабатываю прототип ритм-игры для Android и iOS на Kotlin Multiplatform. Работаю над игровыми механиками, обработкой аудио и точной синхронизацией музыки с действиями игрока.

**Стек:** Kotlin, Kotlin Multiplatform, Compose Multiplatform, Material 3, Kotlin Serialization.

**[CareProject](https://github.com/NolReaction/CareProject)**  
Делаю экшен-игру на Unity: сражения роботов, разные режимы и развитие персонажа. Реализую игровые системы, поведение противников, визуальные эффекты и инструменты для настройки игры.

**Стек:** C#, Unity, URP, Blender.

**[Я живой / Мохлик](https://github.com/NolReaction/zhiv-app) · [Веб-версия](https://im-alive.ru/)**  
Разрабатываю приложение, которое объединяет связь с близкими и собственный лесной мир с хозяйством, рыбалкой и путешествиями. Работаю над всем продуктом: веб-интерфейсом, мобильным приложением, игровой логикой и сервером на Kotlin.

**Стек:** Kotlin, Ktor, PostgreSQL, TypeScript, React, Next.js, Capacitor, Swift, Docker.

**[Авто-Горизонт](https://auto-gorizont.ru/)**  
Для компании по поставкам строительных материалов разработал сайт с приёмом заявок и рабочим местом диспетчера. Связал публичную часть сайта с обработкой обращений внутри компании. Исходники закрыты.

**Стек:** JavaScript, HTML/CSS, Node.js, Canvas 2D, Docker Compose, Caddy.

**[Alfa AutoML Agent & Alfa Lab](https://github.com/NolReaction/alfa-automl-agent)**  
Участвовал в хакатоне «Альфа-Будущее». В команде отвечал за архитектуру и основную разработку агента для решения ML-задач и приложения для проведения экспериментов. Объединил машинное обучение, автоматический подбор моделей и работу с LLM.

**Стек:** Python, pandas, scikit-learn, CatBoost, LightGBM, Optuna, LLM API.

**[AutoHub](https://github.com/NolReaction/AutoHub)**  
Написал Android-приложение для своего автомобильного гаража. Самостоятельно выстроил архитектуру, работу с локальными данными и интерфейс на Jetpack Compose.

**Стек:** Kotlin, Jetpack Compose, MVVM, Coroutines/Flow, Room, Hilt, DataStore.

**Дипломный проект по логистике**  
Разработал Android-приложение для логистики инертных материалов и сервер на Spring Boot. Реализовал работу с рейсами, документами, геопозицией и общением между водителем и диспетчером. Исходники закрыты.

**Android:** Kotlin, XML/ViewBinding, Retrofit, Room, Coroutines.  
**Backend:** Kotlin, Spring Boot, Spring Security, PostgreSQL, JWT, REST API.

**Auto Sniper**  
Разработал Telegram-бота для поиска автомобильных объявлений по заданным условиям. Разделил получение и обработку объявлений и взаимодействие с пользователем. Исходники закрыты.

**Стек:** Python, aiogram, asyncio, SQLAlchemy, PostgreSQL, Telegram Bot API.
